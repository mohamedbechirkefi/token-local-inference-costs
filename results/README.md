# results/

Machine-readable experiment outputs, one folder per run (`RUN-<EXP>-NNNN/`: `result.json` validated against schema 1.0.0, `run_manifest.json`, `config.json`, and the generated `report.md`, `metrics.csv`, `contrasts.csv`, `latency.svg`, optionally `report.pdf`).

- `exploratory/`: exploratory runs only. Never findings, never inputs to confirmatory analysis. RUN-SMOKE-0001 to 0004 are harness smoke runs on the SIMULATED backend with a synthetic fixture (journal JRN-0003): no model ran. RUN-SMOKE-0005 (matrix) and RUN-SMOKE-0006 (5 cold and 5 warm A0 trials) are the real-runtime smoke runs of M3 (JRN-0006). M4-EXPL-0001 is the M4 re-analysis of the committed RUN-EXP-003-0001 records (no inference; JRN-0009, DL-012), generated by `scripts/m4_exploratory_exp003.py`.
- `confirmatory/`: created by the runner only for configs whose protocol the owner has frozen. As of M3 (2026-11-25) it holds RUN-EXP-003-0001 (EXP-003, complete; `sha256_manifest.json` lists the file hashes). EXP-001 and EXP-002 aborted before any request and wrote nothing (DL-011).
- `raw/`: large generated outputs and local copies of external data; ignored by git.
