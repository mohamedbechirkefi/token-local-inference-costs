# Claims audit checklist (empty at M0: no claims)

- [ ] Every row of `research/claims_register.csv` has an evidence path or verified source that resolves.
- [ ] Every number matches the raw result file (denominator, unit, precision, sample count).
- [ ] Measured and modelled values are labelled and never mixed.
- [ ] Every external claim maps to a source marked opened in `research/literature_review.md`.
- [ ] No causal or general claim beyond the configurations, machine and runtime measured.
- [ ] Null and negative results are reported; failed runs are listed.
- [ ] Second review pass challenged the preferred hypothesis (recorded here with date).
